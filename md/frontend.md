## 1. 專案概述
打造一個結合 **AI 智能對話**、**即時數據儀表板 (Dashboard)** 與 **模擬下單功能** 的加密貨幣交易助手前端介面，提供使用者完整的 AI 分析與交易決策流程。

---

## 2. 核心功能需求

### ✅ 核心需求一：AI 助手對話介面 (Chat Interface)
**狀態**: 已完成基礎畫面
- **對話互動**：提供直覺的聊天室視窗，支援使用者輸入對話與指令（如：「分析 BTC」、「ETH 現在能買嗎？」）。✅
- **對話歷史**：支援保留並展示歷史對話紀錄。✅
- **策略設定**：可調整交易人格（如：Degen / Conservative）與啟用的技術分析工具（如：布林通道、均線、社群情緒）。✅

### ✅ 核心需求二：動態儀表板生成 (Dashboard Section)
**狀態**: 已完成基礎畫面
- **自動觸發**：在對話框收到分析指令後，系統於對話訊息內或下方自動生成 **Dashboard 區塊**。✅
- **儀表板內容**：
  - **數據卡片 (Metrics)**：顯示當前價格、24h 漲跌幅、RSI 指標、共識評分 (Confluence Score) 等。✅
  - **視覺化圖表**：嵌入互動式 K 線圖（Candlestick Chart）與技術指標圖表。✅
  - **綜合報告**：包含文字分析理由、買賣建議（買進/賣出/觀望）與指標貢獻度表格。✅

### ✅ 核心需求三：多頁籤架構 — 獨立下單頁面 (Order Tab)
**狀態**: 已完成基礎畫面
- **Tab 1（AI 對話與分析）**：專注於聊天對話與檢視產出的分析 Dashboard。✅
- **Tab 2（模擬下單儀表板）**：獨立的交易頁面，包含：✅
  - **下單表單**：選擇買賣方向 (Buy/Sell)、委託類型 (Market/Limit)、數量與價格輸入。✅
  - **幣種連動**：在 Tab 1 完成對話分析後，自動將建議幣種帶入 Tab 2 的下單表單。✅
  - **持倉與紀錄**：顯示當前模擬帳戶餘額、持有部位與交易歷史。✅

## 3. 技術選型與環境架構

- **建議框架**：`Streamlit` ✅
  - **選型理由**：
    1. **原生 Multi-Tab 支援**：使用 `st.tabs` 即可快速建立靈活的頁籤切換。✅
    2. **豐富的 Dashboard 元件**：內建 `st.metric`（數據卡片）、`st.columns`（多欄排版）與 `st.plotly_chart`（圖表繪製）。✅
    3. **全同步架構**：避免 Windows 環境下非同步事件迴圈 (`asyncio` / `anyio`) 的相容性問題。✅
- **搭配套件**：
  - `plotly`：繪製專業互動式 K 線圖與技術指標。✅
  - `pandas` / `numpy`：數據處理與模擬行情計算。✅

## 6. 使用方式

### 安裝依賴
```powershell
pip install -r requirements.txt
```

### 啟動 Streamlit 應用
```powershell
streamlit run app.py
```

應用將在瀏覽器自動開啟，預設網址：`http://localhost:8501`

## 7. 功能特色

### Tab 1: AI 對話與分析
- 💬 **聊天介面**：輸入幣種（如 BTC、ETH）進行分析
- 📊 **即時儀表板**：
  - 數據卡片：價格、RSI、共識評分、建議動作
  - K 線圖：包含布林通道、移動平均線（MA7、MA25）
  - 綜合報告：指標貢獻度、建議理由
- ⚙️ **策略設定**：側邊欄可切換交易人格（Conservative/Degen）

### Tab 2: 模擬下單
- 📝 **下單表單**：
  - 自動帶入 Tab 1 分析的幣種
  - 支援市價單/限價單
  - 支援買進/賣出操作
- 💰 **帳戶管理**：
  - 顯示模擬餘額（初始 $10,000）
  - 即時更新持倉與損益
- 📜 **交易歷史**：完整記錄所有交易
